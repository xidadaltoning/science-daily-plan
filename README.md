# 科研日课 · Research Daily

一个**本机运行**的科研日程管理与记录工具：每日科研安排、科研目标、实验计划、文献阅读、专注计时、数据复盘，全部在一个页面里完成。

无需安装、无需注册、不联网 —— 双击 `启动科研日课.bat` 即可使用，数据自动保存到本机文件。

---

## 一、如何打开

- **方式一（推荐）**：双击 `启动科研日课.bat`
  会在本机启动一个数据服务并自动打开浏览器。数据写入 `data\科研日课数据.json`，每天还会自动留一份快照备份；Chrome 与 Edge 看到的是同一份数据，清理浏览器也不会丢。
- **方式二（离线备用）**：双击 `打开科研日课.bat`（或直接打开 `index.html`）
  不需要任何服务，数据保存在当前浏览器本地，适合临时使用、或电脑上没有 Python 时。
- **停止服务**：双击 `停止科研日课.bat`，或直接关掉那个最小化的「科研日课·本地服务」窗口。
- **每天一键打开**：右键 `启动科研日课.bat` → 发送到 → 桌面快捷方式。

> 方式一需要电脑装有 Python 3（科研电脑通常都有）；没有时脚本会自动退回方式二，功能一样，只是数据存在浏览器里。

## 二、核心功能

### 1. 今日（默认首页）
- **快速记录**：一行文字搞定一条任务，支持自然写法
  `9:00-10:30 细胞传代 #实验 !高 @90m`
  - 时间范围 `9:00-10:30`、单点时间 `14:00`
  - 类别 `#实验 #文献 #写作 #数据 #组会 #课程 #事务 #其他`
  - 优先级 `!高 !中 !低`（或 `!!` 表示高）
  - 预计时长 `@90m` / `@1.5h`；日期 `@明天 @后天 @2026-10-20 @10/20`
- **常规安排**：每天 / 工作日 / 周末自动出现的固定动作，按天打卡
- **今日安排**：按时间排序，支持勾选完成、编辑、顺延到明天、拖动排序；过期任务有橙色提示，正在进行的时段有「进行中」标记
- **今日进度**：任务完成率、专注时长（对每日目标）、本周任务与专注
- **实验动态 / 文献阅读**：一屏看到正在推进的实验与在读文献，可一键记录进展、+15/+30 分钟阅读
- **灵感速记**：随手记想法，`Ctrl + Enter` 保存

### 2. 日程安排
- 周概览条：一周 7 天任务分布与完成率，点击任意一天切换
- **时间轴**：06:00–24:00，任务按真实时段成块显示，重叠任务自动分栏；**点击空白时段直接在该时间创建任务**；今天有实时红线标示当前时间
- 侧栏：当日小结、快速添加、常规安排、未安排时间的任务（一键安排时段）
- 一键「复制当天计划」为纯文本，方便粘贴到微信 / 群聊

### 3. 科研目标
- **目标卡片**：投稿 / 实验 / 学习 / 项目 / 答辩等类型，状态（推进中 / 已完成 / 已暂停 / 已归档）、起止日期、完成度与临期提醒
- **里程碑**：把目标拆成带日期的关键节点，勾选即自动计算进度（也可以改用手动进度）
- **甘特时间轴**：所有目标的起止条 + 里程碑菱形 + 今天竖线，一眼看清整体节奏
- **关联实验 / 文献**：目标可以挂上正在推进的实验与正在读的文献
- **一键转任务**：目标卡片上的「+ 今日任务」直接把目标变成今天可执行的一条任务
- **模板起步**：投稿一篇论文 / 掌握一项新技术 / 学位论文阶段任务，点一下就生成里程碑

### 4. 实验计划
- **看板视图**：计划中 / 进行中 / 已完成 / 已暂停·终止，卡片可直接拖动改状态
- 列表视图 + 标签筛选 + 搜索 + 排序
- **实验详情**（点击卡片）：
  - 研究目标、研究假设、材料与试剂、实验方案
  - **步骤清单**：把实验拆成可勾选的小步骤，自动计算进度
  - 结果记录、结论与反思
  - **进展记录**：随时追加时间线记录，实验过程完整留痕
  - 关联文献

### 5. 文献阅读
- 文献库：卡片 / 列表两种视图，状态（待读 / 在读 / 已读）、标签、评分、阅读进度
- **阅读记录**：`+15m` / `+30m` / 自定义分钟数，自动累计阅读时长并计入今日专注统计
- 笔记区：摘要总结、关键发现、疑问与批判、好句摘录
- **BibTeX 批量导入**：从 Zotero / EndNote / Google Scholar 复制多条记录粘贴即可，自动解析标题、作者、期刊、年份、DOI、摘要、关键词，并按 DOI 去重
- 一键打开 DOI 原文链接

### 6. 复盘统计
- 区间切换：近 7 天 / 近 30 天 / 近 90 天 / 本周 / 本月
- 关键指标：完成任务（含环比）、专注时长、番茄个数、文献阅读、实验记录、连续活跃天数
- 图表：任务与专注趋势、专注时间分配（环形图）、任务类型分布、实验与文献状态、**近 16 周科研活跃热力图**
- **周复盘**：本周进展与收获 / 遇到的问题 / 下周计划，可回溯任意一周
- **生成周报**：一键生成 Markdown 周报（含每日明细），可复制或下载 `.md`
- 「打印 / 导出 PDF」可把统计页面存成 PDF

### 7. 设置
- 个人称呼、研究方向、每日专注目标、每日 / 每周任务目标
- 番茄钟：专注 / 短休息 / 长休息时长、几个番茄后长休息、提示音、自动进入下一阶段
- 外观：跟随系统 / 浅色 / 深色，6 种强调色
- 数据：导出 JSON 备份、导入（合并 / 覆盖）、导出全部内容为 Markdown、载入示例数据、清空数据

### 8. 番茄钟（专注计时）
- 三种模式：专注 / 短休息 / 长休息，圆环倒计时
- 可关联具体任务：完成后自动按任务类别记录专注时长
- **跨页面常驻**：切到别的页面时，右下角悬浮窗继续计时；刷新页面也不会丢失进度
- 专注结束播放提示音，并把本次时长写入统计

## 四、数据与备份（重要）

**用 `启动科研日课.bat` 打开时（推荐）**
- 所有数据实时写入本机文件 `data\科研日课数据.json`，不上传、不联网。
- 每天首次保存时自动生成一份快照，存在 `data\backups\`（最多保留 120 份）；主文件万一损坏，会自动回退到最近一次备份。
- 「设置 → 数据存储与备份」里可以：打开数据文件夹、复制路径、立即备份、导出 JSON。
- 想再稳一点：把整个 `data` 文件夹放进网盘同步目录（OneDrive / 坚果云等），等于自动云备份。

**用 `index.html` 打开时（离线模式）**
- 数据保存在当前浏览器本地（localStorage），请固定使用同一个浏览器。
- **建议每周在「设置 → 导出 JSON 备份」一次**；清理浏览器数据、换浏览器或换电脑前，请先导出。

**换电脑 / 恢复数据**
- 把整个「科研日课」文件夹拷过去即可（包含 data 文件夹）；
- 或在新电脑用「设置 → 从备份导入」，支持「合并追加」与「完全覆盖」两种方式；
- 想整理成 Word / Notion 文档，用「导出全部内容为 Markdown」。

## 六、常见问题

**Q：数据会丢吗？**
用 `启动科研日课.bat` 打开时，数据写在 `data\科研日课数据.json` 并每天自动留快照，基本不会丢；离线模式下只要不清理浏览器数据也不会丢。

**Q：双击启动脚本一闪而过 / 提示没有 Python？**
说明电脑里没有找到 Python，脚本会自动改用离线模式打开界面（数据存浏览器）。想用本地文件模式，装一个 Python 3（python.org 下载，安装时勾选 Add Python to PATH）即可。

**Q：提示端口被占用怎么办？**
服务会自动在 8787–8811 之间挑选空闲端口，一般不需要处理；若提示全部被占用，关掉占用端口的程序再启动即可。

**Q：同时用两个浏览器打开会冲突吗？**
不会，它们连的是同一个本地服务、写同一个数据文件。建议同一时间只在一个窗口里编辑。

**Q：手机上能用吗？**
界面做了响应式适配，但数据在本机。手机端可以先在电脑上「导出 JSON 备份」，再传到手机浏览器导入。

**Q：能在手机上看吗？**
页面做了响应式适配，界面会变成窄屏版。但因为数据存在电脑浏览器里，手机端需要自行用备份文件导入。

**Q：可以多人共用 / 同步吗？**
当前是单机版。如需多设备同步，可在「导出 JSON」后放到网盘，在另一台设备用「导入」实现手动同步。

**Q：示例数据怎么删掉？**
「设置 → 清空所有数据」可以一次性清空；也可以在「设置 → 载入示例数据」前先清空。

**Q：实验记录能导出去写论文吗？**
可以。用「设置 → 导出全部内容为 Markdown」，实验的目标、假设、方案、步骤、结果、结论与进展记录都会导出，可直接用于写方法部分。
